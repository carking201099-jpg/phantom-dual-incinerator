# 🔥 Phantom Dual Incinerator

A clean, non-custodial web app to **burn tokens** on **Solana** and **Ethereum** using **Phantom Wallet**.

## Features

- Direct Phantom Wallet integration (Solana + Ethereum EVM)
- Dynamic token decimals detection (no more manual decimal errors)
- Adjustable burn fee (0% – 2%) via slider
- Popular token quick-select buttons
- Real-time gas / transaction cost estimates
- Mobile-friendly + PWA installable
- Clean dark cyber theme

## How to Use

1. Visit the deployed site
2. Click **Connect Phantom** (Solana tab) or **Connect Phantom Ethereum**
3. Enter token mint/contract or use quick buttons
4. Adjust amount and burn fee slider
5. Click **🔥 BURN** 

> **Warning**: Burning is **permanent and irreversible**. Always test with small amounts first.

## Tech Stack

- Solana Web3.js + SPL Token
- Ethers.js v5
- Phantom Wallet (Solana + EVM)
- Pure HTML/CSS/JS (no backend)

## Security Notes

- The app runs **entirely in your browser**
- No servers, no custody of your keys
- Transactions are signed directly by Phantom
- Always verify token addresses before burning
